# TPI-02 em Java

Projetos organizados no padrão de pastas Java (`src/main/java`), um por exercício:

- `exercicio-01`: verificar se número é múltiplo de 3.
- `exercicio-02`: ler três números e mostrar em ordem crescente.
- `exercicio-03`: calcular valor de venda com lucro de 45% (compra < 20) ou 30%.
- `exercicio-04`: classificar classe eleitoral pela idade.
- `exercicio-05`: calcular valor do plano de saúde por faixa etária.

## Compilar

```bash
javac exercicio-01/src/main/java/Main.java
```

## Executar

```bash
java -cp exercicio-01/src/main/java Main
```

Repita para cada pasta (`exercicio-02`, ..., `exercicio-05`).
